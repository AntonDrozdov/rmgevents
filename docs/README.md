## Как читать и обновлять

- «Часть 1» документа вкладки предназначена для пользователя и описывает видимое поведение.
- «Часть 2» предназначена для разработчика: API, DTO, файлы, ограничения и проверки.
- При изменении API одновременно обновляйте таблицу маршрутов, DTO и пользовательский сценарий.
- Секреты, SID, реальные пароли и содержимое `deploy/.env.ai` в документацию не добавляются.
- Файл [yandexmodels_29102026.md](../deploy/yandexmodels_29102026.md) — датированный локальный справочник цен, а не источник доступности моделей. Доступность AIMode получает через Models API Yandex.

## Текущая платформа

- Backend: .NET 10, ASP.NET Core 10, EF Core 10.0.14, Npgsql EF 10.0.3.
- Frontend: React 19, TypeScript, Vite; контейнер собирается Node 24 и обслуживается Nginx 1.30.6.
- PostgreSQL — постоянное хранилище приложения.
- Redis и Kafka в текущей конфигурации не используются.

Команды локальной сборки и порядок работы с Docker приведены в [deploy/README.md](../deploy/README.md).
